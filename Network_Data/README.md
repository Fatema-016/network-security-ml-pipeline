# Network Data

This folder contains the raw CICIDS 2017 CSV files used for this project.

## Files Used
- Wednesday-workingHours.pcap_ISCX.csv
- Friday-WorkingHours-Afternoon-DDos.pcap_ISCX.csv
- Thursday-WorkingHours-Morning-WebAttacks.pcap_ISCX.csv

## Download
Download from the official source:
https://www.unb.ca/cic/datasets/ids-2017.html

Choose: MachineLearningCSV.zip

## Note
After downloading, run `push_data.py` from the project root
to push the data into MongoDB Atlas.
